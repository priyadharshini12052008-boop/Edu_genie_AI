# EduGenie – AI-Powered Learning Assistant

## 📌 About the Project

EduGenie is an AI-powered learning assistant that helps students learn, practice, and revise using Generative AI.

### 🚀 Features

- Ask a Question
- Explain a Topic
- Generate Quiz
- Generate Summary
- Recommended Learning Path
